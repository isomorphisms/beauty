# Moving-face demonstration

Open `moving-face.html` in a browser. It is self-contained: no network, server,
package installation or compilation is needed to use the demonstration.

- Select a muscle, raise its activation, and optionally recruit both sides.
- Inspect composite expression buttons and all six mandibular directions.
- “Close from open” applies closing recruitment against the open-jaw inputs.
- Use the 36-control panel to combine expressions without canned mesh morphs.
- Drag the face to orbit. Anatomy view shows influence, attachment direction,
  mandibular structure, hyoid and optionally projected landmarks.
- Animate pulses the selected muscle. Neutral/reset clears activations.

The mesh is a procedural anterior face/neck mask with real eye and mouth
apertures: 2229 connected vertices and 4184 triangles. The rigid mandible has a
separate transform. This is an executable geometric reference, not a full head,
subject-specific fit, validated force solver, polished character, or APK.

The source path is `examples/autogenerated/moving-face/`: `model.mjs` maps the
existing controls to anatomy, solves the skeleton, then deforms tissue;
`render.mjs` only projects/renders that surface. `make-demo.mjs` bundles those
exact sources and the canonical TSV/controls into this one HTML file. Its
`--check` option catches a stale bundle.

`test.mjs` checks structural and anatomical wiring, visible landmark direction,
neutral identity, asymmetry, skeletal rigidity, shared oral junctions, finite
fields and fold resistance. `render-test.mjs` executes the same renderer in CPU
Canvas and produces image/RMS fixtures. `browser-test.mjs` executes the bundled
HTML in Chromium and checks actual UI behavior and rendered pixels. Browser
and Canvas dependencies belong on a test host; they are not demo dependencies.
Node 24 is the verified reference-test host. The browser test accepts an
explicit `BEAUTY_CHROMIUM_EXECUTABLE` or Playwright's installed Chromium.

Composite tissue shortening is bounded, and combined fields are backtracked
when a triangle would invert or fall below 2.5% rest area. The visible “tissue
strain scale” exposes that attenuation. No expression-specific geometry is
selected. This cheap guard is not a substitute for a future volumetric tissue
or contact solver. In particular, strong bilateral smile can be attenuated.
